# RE-PLAY — TERRANOVA X

Pàgina web estàtica en català per presentar el projecte RE-PLAY i el controlador TERRANOVA X.

## Contingut
- `index.html`: estructura i contingut de la pàgina.
- `styles.css`: disseny adaptable a mòbils, tauletes i ordinadors.
- `script.js`: menú de navegació per a pantalles petites.
- `assets/`: logotip i il·lustració SVG del controlador.

## Publicar a GitHub Pages
1. Crea un repositori nou a GitHub.
2. Descomprimeix aquest ZIP i puja tots els fitxers i la carpeta `assets` al directori principal del repositori.
3. Ves a **Settings → Pages**.
4. A **Build and deployment**, selecciona **Deploy from a branch**.
5. Tria la branca `main` i la carpeta `/ (root)`, i desa els canvis.
6. GitHub publicarà la pàgina i mostrarà l'adreça web a l'apartat Pages.

## Personalització
Canvia l'adreça `info@re-play.example` de `index.html` per un correu real abans de publicar la web. La connexió Bluetooth i la compatibilitat del producte es presenten com a característiques del concepte; caldrà validar-les amb el maquinari real.
