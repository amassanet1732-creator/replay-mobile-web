RE:PLAY MOBILE — WEB PER A GITHUB PAGES

1. Descomprimeix el ZIP.
2. Entra a https://github.com i inicia sessió.
3. Prem el botó + (a dalt a la dreta) i selecciona New repository.
4. Escriu un nom, per exemple: replay-mobile-web
5. Selecciona Public i crea el repositori.
6. Prem Add file > Upload files.
7. Puja index.html i prem Commit changes.
8. Ves a Settings > Pages.
9. A Build and deployment, selecciona Deploy from a branch.
10. Tria la branca main i la carpeta /(root), i prem Save.
11. Espera un minut o uns quants minuts. GitHub et mostrarà l'adreça de la web a Settings > Pages.

EDITAR LA WEB
- Per canviar textos, obre index.html al repositori, prem la icona del llapis, edita i fes Commit changes.
- Per canviar el correu, cerca reloopgaming@example.com i posa-hi el correu del projecte.
- Les fotografies són enllaços d'Unsplash i necessiten connexió a internet per aparèixer.
- El nom ReLoop Gaming és una proposta provisional: el pots canviar directament dins index.html.

IMPORTANT
Aquesta web presenta el concepte i el prototip escolar. No afirmis que el comandament ja és compatible amb tots els mòbils o jocs: s'ha de programar i provar amb dispositius i jocs compatibles.
